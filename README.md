# Skills

Skills para Claude Code, feitas no meu dia a dia de marketing e automação. Licença MIT.

| Skill | O que faz |
|---|---|
| [edicao-video-com-memoria](edicao-video-com-memoria/SKILL.md) | Edita Reels e TikToks a partir do bruto com um manual de estética e uma memória de feedback que melhora a cada vídeo |

Instalar: copiar a pasta da skill para `~/.claude/skills/`.

## Hooks e automações

| Pasta | O que faz |
|---|---|
| [hooks-effort-e-foco](hooks-effort-e-foco/README.md) | Dois hooks: um avisa quando o pedido pede outro modelo ou effort, o outro só deixa construir ferramenta na janela de horário que você escolher |
| [fila-agendada](fila-agendada/README.md) | Deixa o Claude Code trabalhando sozinho numa lista de tarefas, num horário marcado no Agendador do Windows, e gravando um relatório no fim |
