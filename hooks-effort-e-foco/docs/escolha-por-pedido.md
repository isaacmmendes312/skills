# Escolha por pedido (modelo e effort)

Tabela lida pelo hook `modelo-effort.py`. É um ponto de partida: ajuste com o que você testar nas suas tarefas reais.

| Pedido | Basta | Subir para |
|---|---|---|
| Pergunta rápida, organizar arquivo, formatar, extrair dado de texto, mexer em lista de tarefas | Sonnet ou Haiku, low | |
| Texto com modelo pronto (e-mail, legenda, roteiro), editar notas, ajuste pequeno em site | Sonnet, medium (ou Opus auto) | |
| Etapa de projeto já planejada, edição de vídeo, protótipo com skill | Opus auto (medium) | high se travar |
| Bug em código existente, etapa grande, revisão de código | Opus high | |
| Planejar projeto inteiro, arquitetura, decisão difícil com muita coisa em jogo, auditar skill, o high já falhou | Opus xhigh | |
| Auditoria de segurança ou varredura grande sozinha | Opus max (raro) | |
